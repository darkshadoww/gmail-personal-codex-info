Lalit Personal Gmail to Codex

A private, owner-operated utility that receives Google Gmail push notifications and routes incoming personal email to a dedicated Codex triage conversation. It uses Google Pub/Sub push delivery, without mailbox polling.

The watcher requests only Gmail metadata access. The owner’s separately connected Gmail account reads conversations and performs authorized triage. This utility is for its owner’s personal use and is not offered as a public service.
